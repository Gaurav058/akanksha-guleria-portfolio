## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Google Fonts (`Plus Jakarta Sans` & `Cormorant Garamond`)
- **SEO**: Schema.org JSON-LD (`Person` & `ProfilePage`), `sitemap.xml`, `robots.txt`, OpenGraph metadata

## Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
